Task 1 15 Points

Book a Train Ticket

Pixel-faithful recreation of the ticket booking interface across 1280px (laptop) and 375px (phone) viewports.

  • Exact brand palette: #0F6B5F, #F2A93B, #16302B, #F4F7F5, #E6EFEC
  • Typography: Google Fonts Montserrat
  • Segmented "One way / Round trip" radio pill toggle
  • Mobile Button Reorder: Find trains sits above Clear on phones without changing HTML order
  • 100% keyboard and screen reader accessible

Task 2 15 Points

AITU Hack 2026 Registration

Full student hackathon registration form validated strictly through native HTML5 attributes without regex patterns or JavaScript.

  • 13 fields configured with exact type, min, max, step, minlength, maxlength
  • Time validation: 09:00–18:00 with step="1800" (30 mins)
  • Modern CSS :user-invalid and :user-valid feedback
  • Errors appear only after user interaction, never on load
  • Includes an interactive live verification table with test cases
View Task 2 Live
Task 3 15 Points

Fix a Bad Form (Audit)

Deep architectural analysis and rebuild of a broken café table reservation form.

  • Audit of 14 distinct usability, accessibility, and submission bugs
  • 2 alternative fixes with comprehensive architectural trade-off justification
  • Rebuilt in clean Bootstrap 5.3 with semantic fieldsets, connected labels, real submit button
  • 100% compliant with W3C Markup Validator and keyboard navigation
